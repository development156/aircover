The four-rung status ladder

No red, amber or green. Status is carried by fill weight, a glyph and a label — loudest to quietest is urgency, not good to bad. Print this page in greyscale: every rung is still readable.

◷ In review

✓ Published

Rung 4 — done, scheduled, informational. Grey outline.
