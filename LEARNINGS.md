Limits come from `PLAN_CATALOG` (the DB `plans.limits` is its seeded fold and typed as loose `JsonbSchema`), made honest by a new real-DB **drift test** asserting the table equals the catalog — nothing asserted that before, so DB and code could drift silently. (4) **Cashfree**: signature is `base64(HMAC_SHA256(secret, x-webhook-timestamp + rawBody))`, timestamp first, no separator — this REPLACED a pre-2022 `ksort` scheme that most online snippets still show. Tests recompute the expectation from the spec rather than pasting a constant. Verify over the **raw** body: a re-stringified parse normalizes `1.80` → `1.8` and breaks the HMAC. (7) **`CASHFREE_ENV` is required and never defaulted**: sandbox and production credentials are structurally identical with no distinguishing prefix, so nothing downstream can catch a prod key aimed at the wrong host; `baseUrl` is derived from it so the two cannot disagree. (8) **BLOCKER — `.env` has `CASHFREE_APP_ID` == `CASHFREE_SECRET_KEY`** (byte-identical, verified without printing either), so live sandbox returns 401 and the tag echo stays unverified; live tests gated behind `CASHFREE_LIVE=1` so a broken credential does not redden the default suite.
